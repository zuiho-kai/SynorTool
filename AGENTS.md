Project-specific instructions
When a problem is identified, follow this sequence before making any modification:
1. Locate and inspect the relevant code first. 2. Tell the user which files the proposed modification will affect and which features or behaviors it may impact. 3. Wait for the user's explicit confirmation. 4. Start modifying files only after that confirmation.
Do not begin implementation, formatting, refactoring, or packaging that depends on the proposed change before confirmation. Read-only investigation and reporting are allowed before confirmation.on.
